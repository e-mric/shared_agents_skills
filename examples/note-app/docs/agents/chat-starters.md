# Focused chat starters

These roles can run sequentially in one chat. They do not require four people or agents.

## Product and experience
Read AGENTS.md, docs/index.md, docs/project-state.md and docs/product.md. Resolve one
note-taking question. Separate evidence, hypotheses and proposals. Record accepted intent,
recovery states, accessible interactions and observable criteria in the owning document.

## Research and studies
Read the project guidance and state. Answer one bounded question about browser storage
or note-taking behavior. Prefer primary sources, date evidence and state uncertainty.
Update docs/research.md without inventing user demand.

## Implementation
Read the guidance, state and accepted product criteria. Deliver one complete note journey.
Inspect current files first. Preserve drafts on failure, test meaningful behavior and
review the experience. Update evidence and remaining work in docs/project-state.md.

## External testing
Read the guidance, state, product criteria and demo script. Independently evaluate a named
revision using test notes. Check save/reload, interrupted writes, cancellation and keyboard
use. Report reproducible findings and limits. Testing alone does not authorize production changes.
